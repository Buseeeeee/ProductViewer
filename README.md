ProductViewer - Ürün ve Stok Yönetim Sistemi

C# ile geliştirilmiş, konsol tabanlı bir ürün ve stok yönetim uygulamasıdır. Ürünleri eklemeyi, listelemeyi, aramayı ve silmeyi sağlar. Ürün bilgileri JSON dosyasında saklanır ve program yeniden başlatıldığında tekrar yüklenir.

Özellikler

* Ürün ekleme
* Kayıtlı ürünleri listeleme
* Ürün adına göre arama
* Ürün silme
* Ürün adı, fiyatı ve stok bilgisini yönetme
* Hatalı fiyat ve stok girişlerini doğrulama
* JSON dosyasına veri kaydetme ve dosyadan veri yükleme

Kullanılan Teknolojiler

* C#
* .NET
* JSON
* Visual Studio Code

Nasıl Çalıştırılır?

1. Projeyi bilgisayarına indir veya klonla.
2. Terminali proje klasöründe aç.
3. Aşağıdaki komutu çalıştır:

dotnet run

Amaç

Bu proje; C# programlama, metotlar, listeler, nesne tabanlı programlama, kullanıcı girdisi doğrulama ve JSON ile dosya işlemleri konularındaki bilgileri uygulamak amacıyla geliştirilmiştir.
